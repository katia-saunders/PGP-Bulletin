# Updating the Reception Bulletin for a new term

Attach the term menu (PDF), timetable (PDF), and key dates (spreadsheet), then use this prompt with Claude:

```
Update the Reception bulletin for [Spring/Summer] Term 2027. Attached
are the new term menu, timetable, and key dates. Keep the design,
layout, and all the features exactly as they are — just replace the
TERM DATA block with the new term's information.

Please also check the school's term dates page
(https://www.parsonsgreenprep.co.uk/school-information/term-dates/)
and update the TERM_DATES array to match — that's the one part of the
data that isn't covered by my attachments, since it spans the whole
academic year rather than just this term, and the school can revise
it at any time.

Also flag anything unusual for this term — one-off uniform
exceptions, INSET days, changes to the menu's weekly rotation, etc.
```
